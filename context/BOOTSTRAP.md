# Bootstrap

Project: FALLOUT NV - GARRYS MOD

GitHub is the canonical durable project-memory and source-history layer.

Before substantial work, read AGENTS.md, GOAL.md, CURRENT_STATE.md, ARCHITECTURE.md, DECISIONS.md and FAILURE_KNOWLEDGE.md, then inspect repository/local implementation state.

The project combines Fallout: New Vegas with selected Garry's Mod systems and THUG2 skateboarding mechanics. Integration must prioritize actual gameplay quality and reproducibility rather than superficial imitation.

Historical chat claims are not automatically verified implementation state. Reconcile them against repository files, local build artifacts, manifests and runtime tests.

Local build/decompilation/testing may use Desktop Commander. Reverse-engineering tasks requiring IDA must use IDA Pro 6.8 per project requirement.
