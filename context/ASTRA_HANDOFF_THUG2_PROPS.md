# Astra Handoff — THUG2 Embedded Environment Props

## Support processing completed
- 106 named THUG2 skate/environment targets were curated across 16 levels.
- Every target has source QB context.
- Position/GLB spatial processing classified 85 as spatial geometry candidates.
- The remaining 21 split into 14 semantic/gap-style identifiers and 7 unresolved named targets; they must not be force-converted as if they were standalone art.
- Converted whole-level GLBs use anonymous leaf names, so original object identity must be correlated from QB position/scene data rather than name matching.

## Astra/model extraction boundary
For each of the 85 spatial candidates: verify the nearby leaf set corresponds to the named object, split only that object from the level, preserve original THUG2 shape/material evidence, convert to FNV, build/validate independent collision and scale, then promote selectively into the compact prop catalog.

Do not import a THUG2 map. Good promoted THUG2 props should replace redundant lower-priority entries so the default Q-menu library stays near 300–320.
